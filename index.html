DocuBot Pro

A documentation assistant that answers from a project's own docs — and knows when to refuse.
On GitHub
PythonRAGGemini APIGuardrailsOffline eval
3retrieval signals scored before every answer
0LLM calls spent on low-confidence questions
100%of decisions written to a reviewable trace log

PROBLEM

A basic RAG assistant passes whatever it retrieves to the model, so weak matches turn into confident-sounding wrong answers.

APPROACH

Added a confidence layer that scores top score, hit count and score gap into HIGH / MEDIUM / LOW, gating what the system does next.

RESULT

LOW refuses and defers to a human without calling the model; MEDIUM answers with a verify caveat; HIGH answers normally.

WHY IT MATTERS

The assistant fails safe instead of hallucinating, and an offline evaluation harness keeps that behavior measurable.
